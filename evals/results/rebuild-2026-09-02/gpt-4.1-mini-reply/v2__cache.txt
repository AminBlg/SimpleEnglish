Users see stale prices because Redis cache holds old values for up to 10 minutes. This delay occurs if the cache expiry time is 10 minutes or if cache update logic does not run after the database changes. To fix this, you must update or delete the cache entry immediately after the database changes the price. Set a shorter cache expiry time, and use cache invalidation or cache update methods when you write to the database. This ensures users get fresh prices from Redis or the database.
