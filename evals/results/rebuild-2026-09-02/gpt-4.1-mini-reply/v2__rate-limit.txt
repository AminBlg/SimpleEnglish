A token bucket is a system that controls how often an action can happen. Imagine a bucket that holds tokens. Each token lets you make one request. Tokens fill the bucket at a steady rate, like 100 tokens every minute. When a user makes a request, the system removes one token. If the bucket is empty, the request is blocked or delayed. This lets users burst some requests if tokens are saved but limits the long-term rate. A token bucket fits this case well because it controls requests per minute and allows some request bursts.
