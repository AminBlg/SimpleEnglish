A backfill is the process of filling existing rows with values in a new column after you add it as NOT NULL. The migration hangs because the database waits to set values on all 20 GB of existing rows. You must run a backfill migration that sets default or calculated values for all rows before enforcing NOT NULL. First, add the new column allowing NULL values. Then, update the table to fill the new column for every row with valid data. After that, alter the column to set NOT NULL to require values in all new rows.
