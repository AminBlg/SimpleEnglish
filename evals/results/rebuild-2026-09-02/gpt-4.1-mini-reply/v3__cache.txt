Users see stale prices because Redis caches the old data, which does not update instantly when the database changes. This delay can happen if the cache expiration time is set to 10 minutes or if cache invalidation does not occur on updates. To fix this, set a shorter expiration time in Redis or update the cache immediately when prices change. Another method is to use cache eviction or publish-subscribe features to refresh cache entries on update. Make sure that the cache and database stay synchronized closely to prevent stale data display.
