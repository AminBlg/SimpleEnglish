Backfill means filling existing rows with values for the new column to satisfy NOT NULL rules. Adding a NOT NULL column without a default value requires updating all 20 GB of data. This update can take time and appear as if the migration hangs. You run a separate backfill script or process to set values for the new column, usually in smaller batches to avoid long locks. After backfill, you make the column NOT NULL if needed and complete the migration.
