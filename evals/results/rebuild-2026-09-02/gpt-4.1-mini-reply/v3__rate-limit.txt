A token bucket is a method to control how often a user can perform actions, like making API requests. Imagine a bucket that holds tokens, each token allows one request. Tokens are added to the bucket at a steady rate, for example, 100 tokens every minute. When a user makes a request, one token is removed from the bucket, and if no tokens remain, the request is denied or delayed. This method fits well for limiting to 100 requests per minute because it allows bursts of traffic up to the bucket size, then enforces the average rate.
