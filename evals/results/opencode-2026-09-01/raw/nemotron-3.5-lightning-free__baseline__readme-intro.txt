sqlpipe is a command‑line tool that synchronizes PostgreSQL tables to Amazon S3 as compressed Parquet files. By translating SQL queries into efficient scan‑and‑write pipelines, it keeps your data lake in sync with minimal latency. The tool supports incremental updates based on primary keys, customizable column selection, and configurable batch sizes for optimal throughput. It integrates seamlessly with existing CI/CD workflows and can be scheduled via cron or managed as a systemd service. sqlpipe abstracts away the complexity of partitioning, compression, and credential management, allowing developers to focus on data pipelines rather than infrastructure. It also logs each run to stdout and optional JSON files for observability. Configuration is via a simple YAML file or environment variables, making deployment straightforward across dev, staging, and production environments.
