sqlpipe synchronizes Postgres tables to S3 as Parquet files. The tool reads data from a Postgres database and writes it to S3 in columnar format for analytics. Configuration uses a YAML file with connection details and table mappings. The tool handles incremental syncs by tracking processed rows since the last run. Scheduled runs work with external schedulers such as cron or systemd timers.

Error output includes the Postgres error code and a failure description. Table filtering reduces data transfer volume by name pattern. The tool preserves data types including timestamps and boolean values during conversion. Installation requires a YAML configuration file with Postgres connection parameters. Usage specifies the configuration file path and target S3 bucket name.
