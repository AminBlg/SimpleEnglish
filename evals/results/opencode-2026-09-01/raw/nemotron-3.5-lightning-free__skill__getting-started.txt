Run the install script to download and set up sqlpipe. The script copies the binary to your bin directory. Create a sqlpipe.yaml configuration file in your home directory. Set your Postgres connection host and port in the file. Make sure that your host can reach the Postgres port. If a firewall blocks the connection, adjust the firewall rules to allow traffic. Run sqlpipe with the command sqlpipe run --config sqlpipe.yaml. The tool reads the config file and connects to the database. If the connection succeeds, the tool starts work immediately. Stop the tool with Ctrl+C when you finish. You can view processing results in the terminal output log. The first run verifies the connection works correctly. Repeat the command to process more data sets as needed. If you need assistance, contact support. The configuration file uses standard YAML format for easy editing. If you have questions about the configuration, read the documentation topic. Store the configuration file in a safe location for future runs.
