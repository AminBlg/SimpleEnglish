sqlpipe is a command-line tool that streams PostgreSQL tables directly to Amazon S3 as Apache Parquet files. Built for reliability at scale, it handles incremental syncs using logical replication slots, automatically partitions output by time or key columns, and resumes interrupted transfers without duplicating data. Configuration is declarative—a single YAML file defines source tables, destination buckets, partitioning strategy, and compression settings.

Designed for data engineers who need analytical datasets in object storage without managing Airflow DAGs or custom ETL pipelines, sqlpipe runs as a standalone binary with no external dependencies. It authenticates via standard AWS credential chains, supports IAM roles for service accounts in Kubernetes, and emits structured JSON logs for observability. Whether backfilling years of historical data or keeping a near-real-time replica for Athena and Redshift Spectrum, sqlpipe turns a complex data movement problem into a repeatable, auditable command.
