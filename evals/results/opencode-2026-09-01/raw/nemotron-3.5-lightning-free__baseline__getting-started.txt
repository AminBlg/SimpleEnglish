sqlpipe is a CLI tool that lets you run SQL pipelines from a yaml config. Install with `curl -sSL https://get.sqlpipe.dev | sh`. After installation, create a `sqlpipe.yaml` config file defining your connection, queries, and output destinations. The config follows a simple key‑value schema: specify `database`, `queries` (an array of SQL strings or file paths), and `output` (format and destination). Once the file is ready, run `sqlpipe run --config sqlpipe.yaml` to execute the pipeline. The command streams results to your chosen sink (stdout, file, or cloud bucket). On first run, sqlpipe prompts for any missing credentials and stores them securely. Check the generated report in `sqlpipe_report.json` for execution details. For advanced usage, see the docs for templating, variable substitution, and plugin hooks. Logs are written to `sqlpipe.log`; you can set `SQLPIPE_TOKEN` env var for authenticated runs. To iterate, edit the yaml and re‑run the command. Explore built‑in helpers with `sqlpipe --help` or visit the online docs for examples.
