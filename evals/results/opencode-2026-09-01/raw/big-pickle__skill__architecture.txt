sqlpipe transfers data from Postgres to Amazon S3 in Parquet format. Three processes work in sequence: a reader, a converter, and an uploader.

The reader connects to a Postgres database and streams rows in configurable batches. A buffer holds the batches until the converter is ready to process them. The converter transforms each batch into a Parquet row group. The uploader writes the row groups to S3 as multipart objects.

If a network error occurs during upload, sqlpipe retries the request with exponential backoff. The pipeline pauses while it retries. When the retry limit is reached, the process stops with an error. This design keeps each stage independent and lets the pipeline handle large datasets without loading all rows into memory.
