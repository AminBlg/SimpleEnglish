sqlpipe is a streaming pipeline that moves data from Postgres to S3 as Parquet files. A reader process executes a query and streams results in fixed-size batches, keeping memory bounded regardless of table size. Each batch passes to a converter that serializes rows into Parquet row groups, producing columnar chunks ready for analytical workloads. The converter handles schema inference, type mapping, and compression. Completed row groups flow to an uploader that writes them as multipart objects to S3, using a retry strategy with exponential backoff to handle transient failures. The three stages run concurrently with backpressure between them, so a slow S3 upload does not cause the Postgres reader to idle unnecessarily. The pipeline is stateless between batches, enabling restart from any checkpoint without data loss or duplication.
