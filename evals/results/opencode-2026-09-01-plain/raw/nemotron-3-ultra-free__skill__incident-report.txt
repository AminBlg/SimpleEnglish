Between 14:02 and 14:31 UTC, 12% of API requests returned HTTP 502 errors. A deploy at 14:02 removed the cache warmup step. Without warmup, the cache stayed cold and requests timed out. The deploy configuration did not include a guard for this step. We reverted the deploy at 14:27. Errors stopped after the revert. The root cause is the missing warmup step in the deploy configuration. We will add a check to prevent this change in future deploys. We will also add monitoring for cache temperature. The incident affected customers in all regions.
