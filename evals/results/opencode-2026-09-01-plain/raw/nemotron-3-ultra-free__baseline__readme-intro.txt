sqlpipe is a command-line tool that copies PostgreSQL tables to Amazon S3 as Apache Parquet files. It reads table data in parallel streams, writes columnar Parquet output with Snappy compression, and maintains a lightweight cursor so you can re-run syncs incrementally. The tool handles schema changes, large tables, and network interruptions without manual intervention. You configure sources and destinations in a single YAML file, then run `sqlpipe sync` on a schedule or on demand. No separate infrastructure, no custom code — just a binary that moves data reliably from Postgres to your data lake.
