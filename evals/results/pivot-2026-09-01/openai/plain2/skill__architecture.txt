sqlpipe reads rows from a Postgres database in batches. A batch contains many rows and limits memory use. You run a reader process to stream these batches continuously. The converter changes each batch into a Parquet row group. A Parquet row group is a group of rows stored in the Parquet format, which compresses and organizes data efficiently. The uploader sends the Parquet row groups as multipart objects to an S3 storage service. Multipart objects let you upload parts of a file separately. The uploader retries parts if the upload fails. This process helps to move large amounts of data reliably and efficiently from Postgres to S3.
