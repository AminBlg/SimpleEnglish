sqlpipe processes data in three main steps. First, the reader process streams rows from a Postgres database in groups called batches. Then, the converter changes these batches into Parquet row groups. Parquet is a file format for efficient column storage. Finally, the uploader writes parts of these Parquet files as multipart objects to an Amazon S3 bucket. Amazon S3 is a cloud storage service. The uploader retries uploads if they fail. This design allows sqlpipe to handle large data efficiently and reliably.
