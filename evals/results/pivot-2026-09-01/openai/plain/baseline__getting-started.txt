# Getting Started

To begin using **sqlpipe**, first install the CLI tool by running the following command in your terminal:

```bash
curl -sSL https://get.sqlpipe.dev | sh
```

This will download and install the latest version of **sqlpipe**.

Next, configure your pipeline by creating a `sqlpipe.yaml` file. This configuration file defines your data sources, transformations, and destinations. A typical `sqlpipe.yaml` contains connection details, SQL queries, and pipeline steps tailored to your workflow. Refer to the official documentation for detailed configuration options.

Once your `sqlpipe.yaml` is ready, run the pipeline with:

```bash
sqlpipe run --config sqlpipe.yaml
```

This command executes the pipeline as defined in your configuration, running the SQL tasks and managing data flow accordingly.

With these simple steps, you’ll have **sqlpipe** set up and running your data pipelines efficiently. For more detailed examples and advanced usage, check the full documentation.
