# ASD-STE100 Issue 9 — writing rules, compressed

53 rules, 9 sections. IDs match the standard.

Rules 1.1 to 1.4 need the dictionary. They are advisory unless
`not-approved.tsv` or `approved.txt` is also in the context window.

## 0. Classify first

Procedural text tells the reader what to do. Descriptive text gives information.
Do not mix the two in one passage. The limits differ.

## 1. Words

- 1.1 Use only these words: a word that the ASD-STE100 dictionary approves, a technical noun, or a technical verb.
- 1.2 Use an approved word only as the part of speech that the dictionary gives.
- 1.3 Use an approved word only with its approved meaning.
- 1.4 Use only the approved forms of verbs and adjectives.
- 1.5 If a word fits a technical noun category, you can use it as a technical noun.
- 1.6 A word that is not approved is permitted only as a technical noun or a technical verb.
- 1.7 Do not use a technical noun as a verb.
- 1.8 Use technical nouns that are approved in your company, industry, or subject field.
- 1.9 Select a technical noun that is short and easy to understand.
- 1.10 Do not use regional words, slang, or jargon as technical nouns.
- 1.11 Do not use different technical nouns for the same item.
- 1.12 If a verb fits a technical verb category, you can use it as a technical verb.
- 1.13 Do not use a technical verb as a noun.
- 1.14 Use American English spelling unless an official directive tells you differently.

## 2. Multi-word nouns

- 2.1 Use a maximum of three words in a multi-word noun.
- 2.2 If a technical noun has more than three words, write it in full.

Break a longer chain with prepositions. Example: "the timeout value for the connection pool".

## 3. Verbs

- 3.1 Use only the verb forms that the dictionary gives.
- 3.2 Use only these forms and tenses: infinitive, imperative, simple present, simple past, simple future, past participle as an adjective.
- 3.3 Use the past participle form as an adjective.
- 3.4 Do not use auxiliary verbs to make complex verb constructions.
- 3.5 Use the "-ing" form only as a technical noun or as a modifier in a technical noun.
- 3.6 Use the active voice. In descriptive writing, the passive voice is permitted only for an agent that is unknown or not important.
- 3.7 Use an approved verb for an action, not a noun or another part of speech.

Rules 3.2 and 3.4 ban the present perfect (`has completed`), the present
continuous (`is running`), and the conditional (`would fail`). Write
`completed`, `runs`, and `fails`.

## 4. Sentences

- 4.1 Write short and clear sentences.
- 4.2 Do not omit words and do not use contractions.
- 4.3 Use a vertical list for a complex text.
- 4.4 Use connecting words and connecting phrases to connect related sentences.
- 4.5 Where applicable, use an article (the, a, an) or a demonstrative adjective (this, these).

Keep "that": "make sure that the file exists".

## 5. Procedural writing

- 5.1 Use a maximum of 20 words in each sentence.
- 5.2 Write one instruction in each sentence, unless two actions occur at the same time.
- 5.3 Write instructions in the imperative form.
- 5.4 Put the condition before the command, with a comma. The reader must know the condition first.
- 5.5 Write notes to give information, not instructions.

## 6. Descriptive writing

- 6.1 Give information gradually. Each sentence has one subject.
- 6.2 Use key words and key phrases to give the text a logical structure. Do not change them.
- 6.3 Use a maximum of 25 words in each sentence.
- 6.4 Use paragraphs to show related information.
- 6.5 Give each paragraph only one topic.
- 6.6 Use a maximum of six sentences in each paragraph.

The imperative form is not permitted in descriptive text.

## 7. Safety instructions

- 7.1 Use an applicable word, for example "warning" or "caution", to identify the level of risk.
- 7.2 Start a safety instruction with a clear and accurate command or condition.
- 7.3 Give an explanation that shows the risk or the possible result.

Example: "Do not run this command against production. The command deletes rows."

## 8. Punctuation and word count

- 8.1 You can use all standard English punctuation marks, but not the semicolon.
- 8.2 Use hyphens to connect words that are directly related.
- 8.3 You can use parentheses for: references, item letters or numbers, work steps, abbreviations, singular and plural forms together, an explanation, an alternative.
- 8.4 In a vertical list, a colon has the same effect on word count as a period.
- 8.5 Text in parentheses counts as one word in that sentence.
- 8.6 Count each of these as one word:
  - A number, alone or with its unit
  - An abbreviation or an alphanumeric identifier
  - Quoted text
  - A title, a heading, or the text on a placard or a label
  - A proper noun of a person, a group, an organization, or a geopolitical entity
- 8.7 A hyphenated word counts as one word.

## 9. Writing practices

- 9.1 If a word-for-word replacement is not possible, use a different sentence construction.
- 9.2 Use each approved word correctly.
- 9.3 When you use two words together, do not make a phrasal verb.
- 9.4 Use a consistent style for terminology and wording.

One word, one meaning, for the whole document. Pick one of check, verify, or
confirm, and keep it.

## Do not change

Code blocks, identifiers, CLI commands, file paths, quoted error messages, and
product names. Each counts as one word toward the sentence limits.
